# LLM 工作台：第一阶段

## 已实现

- 主窗口增加“阅读工作台”和“LLM 工作台”两个标签页，切页保留阅读状态。
- LLM 页隐藏阅读用的 Context Inspector / Repair Queue，返回阅读页恢复原来的显隐状态。
- 同一个模型规模选择：14B 或 30B。分析员、复核员、审查员为同模型的三个角色，后续默认串行。
- 完整 API 地址、实际 model ID、会话 API Key，以及局域网免鉴权测试。
- 非秘密配置保存、取消测试、超时、输出参数名选择、text / json_object / json_schema 短样本测试。
- 显示本次响应耗时、服务报告的 token、会话内连接测试累计和脱敏结果日志。

首期仅接通**连接测试**。章节分析按钮明确禁用；三个角色显示“尚未接通”，
项目和每章节 token 尚无记录，不显示假数据。没有发送或修改小说，也没有建立生产章节上下文。
“测试通过”不代表模型已通过完整结构化分析或证据校验。

## 使用

1. 进入 LLM 工作台，填写工作室实际部署的完整 Chat Completions 地址。
2. 选择 14B/30B，另行填写服务端实际 model ID；规模选择不自动加载/切换服务端模型。
3. 免鉴权的局域网服务可留空密钥。若使用 HTTP，须主动勾选明文传输授权。
4. 点击“测试连接（内置短样本）”；不会读取当前章节。
5. 若基础调用通过，在高级选项中选择 JSON 模式，验证服务实际支持的结构化能力。
   兼容服务可能需要 `max_tokens` 而非 `max_completion_tokens`，由用户明确选择，不静默回退。

地址须为完整 http/https 请求 URL；不接受 URL 凭据、查询参数或片段，不重复拼接路径。
HTTP 仅接受 localhost、回环地址、RFC1918 IPv4 或 IPv6 ULA 地址，且需手动授权。
其他主机必须 HTTPS 并提供密钥；局域网域名首期请改用明确的私有 IP。
不自动跟随重定向，不绕过证书错误，也不自动重试或切换后端。
明文 HTTP 即使在局域网也不加密，用户需自行确认网络可信。

非秘密配置通过用户级 QSettings 保存，密钥与 HTTP 授权只保留在会话中。
退出后须重新输入密钥、重新授权 HTTP；没有“记住密钥”或自动连接。
服务错误只展示安全错误类别和 HTTP 状态，不记录服务返回的原始错误文本、密钥或请求正文。

## 统计口径

- 连接测试 token 单独累计，包含重新测试，且仅保存于当前会话；不冒充项目/章节用量。
- 服务未提供 usage（包括 null）时显示“未提供”，统计为用量未知，不假装零消耗。
- 失败与取消也可能消耗服务端 token；无法得知时计入未知次数。
- 本阶段为非流式请求，没有精确生成时间和首 token 时间，生成速度明确显示“未提供”。
- 输出 token / 总请求耗时可作为“端到端输出吞吐”，含排队、首包等待等，**不是解码速度**。
- JSON 测试校验短样本为唯一字段 `ok: true`，并要求正常结束；截断或无效输出不标记通过。
- text 模式只验证基础传输与正常完成，不宣称已验证 JSON/schema。

## 验证与下一步

自动测试使用本地模拟 HTTP 服务，不依赖真实 API、真实密钥或小说。
覆盖配置不落盘密钥、免鉴权、token 参数、结构化返回、缺失 usage、失败脱敏、取消、
默认鉴权边界、重定向拒绝、页签切换、阅读布局与旧模块回归。
真实工作室连接尚需用户提供地址/model ID 并在界面主动测试。

下一阶段是 Markdown 原文快照、发送预览和版本化上下文，然后接入单章三角色任务，
持久化每章节/项目统计、结果证据和审查意见，再进行真实模型质量验收。
